# Illustration metaphors (draft for approval)

One physical object per slot whose working *is* the idea. No text inside drawings. Motion described is for auto-animated slots only (heroes, footer CTA, scenario page); cards, skills and rules are static frames of the same object.

## Heroes and footer CTA (big, coloured, auto-animated)

| Slot | Object | What moves |
| --- | --- | --- |
| Directory hub | Card-catalogue cabinet, three banks of drawers (scenarios, skills, rules) | Drawers open in turn, an index card lifts from each, settles back |
| Scenarios hub | Music-box drum: pins (skills) on a turning cylinder pluck comb teeth (rules) | Drum turns on its own cadence, plucked teeth light up one by one |
| Skills hub | Hand press: a stack of raw export sheets fed in, one stamped card out | Sheets slide in, platen drops, a single finding card slides out |
| Rules hub | Go / no-go gauge on a bench: parts slide along, only those that fit pass | Parts glide in, the gauge passes one and kicks one aside |
| Footer CTA | A catalogue card tray pulled out, cards tabbed by library, one slot empty (not the full cabinet, so the directory page doesn't show it twice) | A blank card drops into the gap and its tab fills in (your contribution joins) |

## Scenarios (big, monochrome from scenario colour; static on card, animated on page)

| Scenario | Object | Why |
| --- | --- | --- |
| Early read on a new campaign | Press proof: first sheet off a printing press checked against the plate's registration marks | Check the aim before the full run |
| The morning check | A row of identical four-dial panels (one per client), a scanning arm passes each at dawn, one needle drifted | Same four checks, every account, flags not decisions |
| Warm leads from a signal list | Brazier of coals, each a company; bellows dose air, some coals greying, tongs lift a glowing one out | Warm, dosed, routed while still hot |
| Warm leads from ad signals | Gold sluice box: engagement gravel washed, fool's gold rinsed off, nuggets land in a ranked rack | Clean out fakes, keep the real, rank them |
| Who the campaigns really paid to reach | Spray stencil: paint (budget) through the stencil (targeting), overspray outside the edge, masking tape added | Delivery vs targeting, exclusion list = tape |
